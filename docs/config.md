/// TUIrowser Configuration File Format
/// 
/// Create a `.tuirowser.toml` in your home directory to customize behavior.
///
/// Example:
/// ```toml
/// [fetch]
/// user_agent = "Mozilla/5.0 (compatible; TUIrowser/1.0)"
/// timeout_secs = 30
/// max_redirects = 10
///
/// [ui]
/// theme = "dark"  # "dark" or "light"
/// ```
